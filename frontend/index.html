Bank_bana
เปิดเต็มจอเหมือนแอปจริง • ใช้งานออฟไลน์ได้ • ซิงก์อัตโนมัติ
1. บนคอมพิวเตอร์ (Google Chrome / Microsoft Edge)
• มองไปที่ช่องพิมพ์ URL ด้านบนขวาสุด จะมีไอคอน รูปหน้าจอพร้อมลูกศรดาวน์โหลด (Install Bank_bana)
• คลิกที่ไอคอนนั้นแล้วกด "ติดตั้ง (Install)" แอปจะแยกออกมาเป็นโปรแกรมเต็มจอและสร้างทางลัดบน Desktop ทันที
2. บนมือถือ Android (Google Chrome)
• แตะปุ่มเมนู จุด 3 จุด (⋮) มุมขวาบนของ Chrome
• เลือก "ติดตั้งแอป (Install app)" หรือ "เพิ่มลงในหน้าจอหลัก (Add to Home screen)"
3. บน iPhone / iPad (Safari)
• เปิดเว็บนี้ในแอป Safari แล้วแตะปุ่ม แชร์ (Share รูปสี่เหลี่ยมมีลูกศรชี้ขึ้น) ด้านล่างหน้าจอ
• เลื่อนลงมาเลือก "เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)" แล้วกด "เพิ่ม (Add)"
